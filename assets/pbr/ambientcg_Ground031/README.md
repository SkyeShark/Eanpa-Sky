# AmbientCG Ground031

Source: https://ambientcg.com/view?id=Ground031

Downloaded from AmbientCG as the official 1K-JPG archive on 2026-07-17.
AmbientCG distributes this material under Creative Commons CC0 1.0 Universal.

The complete archive is retained, including Color, NormalGL, NormalDX,
Roughness, AmbientOcclusion, and Displacement. Eanpa uses this for compacted
mineral patches within the gravel-first terrain. The current shader keeps the
complete 1K color and normal maps, packs roughness/AO at 512 pixels, and uses
a visually calibrated two-metre scale consistently across terrain LODs. The untouched 1K
displacement image is reserved as an input for the planned WebGPU SPOM path.
