# Additional desert PBR materials

All texture assets listed here are used under the Creative Commons Zero
(CC0) license. The runtime uses the 1K JPEG maps to keep the WebGPU material
blend within a practical memory and bandwidth budget.

## Poly Haven

- [Cliff Side](https://polyhaven.com/a/cliff_side)
- [Rock Face](https://polyhaven.com/a/rock_face)
- [Gravelly Sand](https://polyhaven.com/a/gravelly_sand)
- [Sandy Gravel 02](https://polyhaven.com/a/sandy_gravel_02)
- [Worn Rock Natural 01](https://polyhaven.com/a/worn_rock_natural_01)
- License: [Poly Haven CC0](https://polyhaven.com/license)

Each local polyhaven directory contains diffuse, OpenGL normal, roughness,
ambient-occlusion, and displacement maps downloaded through Poly Haven's
official API.

## ambientCG

- [Ground 080](https://ambientcg.com/view?id=Ground080)
- [Ground 081](https://ambientcg.com/view?id=Ground081)
- [Ground 022](https://ambientcg.com/view?id=Ground022)
- License: [ambientCG CC0](https://docs.ambientcg.com/license/)

Each local ambientCG directory contains the original ambientCG 1K-JPG
archive payload, including color, OpenGL and DirectX normals, roughness,
ambient occlusion, and displacement maps.
