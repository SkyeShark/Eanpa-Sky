# Ziggurat visual references

`ziggurat-scifi-architectural-reference-v1.png` was generated with the built-in
image generation workflow on 2026-07-16 as a modeling and material reference.
It is not a texture and is not loaded by the runtime.

The prompt specifies a realistic PBR Mesopotamian/science-fiction ziggurat:
strictly rectilinear stacked terraces, vertical retaining walls, a legible
gate-to-summit ceremonial route with proper flights and landings, sandstone
masonry, small-scale lapis/carnelian courses, restrained inset gunmetal
systems, flush fasteners, and the red/true-blue Inanna sphere emitters. It
explicitly excludes a smooth Egyptian-pyramid silhouette, floating pieces,
box-clutter greebles, mirror chrome, wall textures on metal, and protruding
low-poly bolts.
