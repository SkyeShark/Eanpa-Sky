# ambientCG Metal010

Dedicated brushed-steel PBR source for the ziggurat panels, processional rail/caps,
and summit dais reveal.

- Source: https://ambientcg.com/view?id=Metal010
- Download: ambientCG `Metal010_1K-JPG.zip`
- Creator/publisher: ambientCG
- License: Creative Commons CC0 1.0 Universal
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-07-16

The source maps are retained unchanged. Runtime channel semantics are explicit:

- `Color.jpg`: sRGB base color
- `NormalGL.jpg`: linear OpenGL (+Y) tangent-space normal
- `Roughness.jpg`: linear grayscale, sampled from `.r`
- `Metalness.jpg`: linear grayscale, sampled independently from `.r`
