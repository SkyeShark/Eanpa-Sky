# Temple asset provenance

- `desert_sandstone_*`: copied from the local SeedThree asset library. SeedThree is MIT licensed; these textures are its generated desert-sandstone PBR set.
- `inanna_orb.glb`: copied from the local Eidoverse model library. Eidoverse's `CREDITS.md` marks bundled `assets/models` content as CC0.

The source assets were copied without changing their binary contents. Runtime code and procedural scene geometry remain part of this project.
